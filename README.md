# ЛК ЛЕО4 — Личный кабинет для IoT устройств

Веб-приложение для управления IoT устройствами, задачами и событиями.

## Возможности

- **Устройства** — список и управление подключёнными устройствами
- **Задачи** — создание и мониторинг задач для устройств
- **События** — просмотр истории событий

## Технологии

- React + TypeScript
- Vite
- React Router
